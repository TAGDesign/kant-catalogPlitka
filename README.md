# Кант — каталог «Сноуборды»

Статическая вёрстка страницы каталога сноубордов интернет-магазина КАНТ.
Исходники сайта, опубликованного на https://marvelous-youtiao-a65dc6.netlify.app/

## Структура

- `index.html` — страница каталога
- `styles.css` — стили
- `app.js` — скрипты (подсказки в поиске, подтверждение региона, кнопка «наверх»)
- `images/` — иллюстрации категорий, фото, QR-код, иконка стрелки
- `fonts/` — шрифты Gilroy (woff2)

## Запуск

Сборка не нужна — просто откройте `index.html` в браузере или поднимите любой статический сервер:

```sh
npx serve .
```
